# LFFC.us: the Website for the Little Free Failure of Capitalism

This is the content we feed into the [Hugo](https://gohugo.io/) static site generator to generate <https://lffc.us>. It's unlikely to be of much interest, but it's not secret, so here it is!

The site is hosted on [GitHub Pages](https://docs.github.com/en/pages), and is generated and put there by [this GitHub Actions workflow](https://github.com/ussjoin/lffc.us/blob/main/.github/workflows/hugo.yaml).
